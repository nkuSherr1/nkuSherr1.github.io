Math mechanisms

Definitions, formulas, and default thresholds for each quantitative field on the daily page; aligned with ths_v15 / v33 core.

热度打分

Score^hot（score）

score

在当日可交易池内，对每个因子 f_k（人气、人气增量、成交额截面、量比、涨幅、话题等）做截面 z-score，再按 ths_v15 锁死权重 w_k 加权求和。Score 越高表示相对全市场的 THS 热度越强。

当日涨幅（ret1）

ret1

信号日相对前一交易日的收盘涨跌幅。用于截断追高（ext_burst / weak_close 硬门）及判定高潮日（通常 r_1 > 4% 且 burst > 2）。

阈值 · 高潮判定：r_1 ≥ 4%

量比（burst / amt_burst）

burst

当日成交额（或成交量）相对过去 5 日均值的倍数，衡量资金突然放量。amt_burst < 1.2 的票不进候选池；与 ret1 联合判定高潮。

阈值 · 进池硬门：burst ≥ 1.2；高潮：burst > 2

20 日涨停基因（gene20）

gene20

过去 20 个交易日内（不含当日）单日涨幅 ≥ 9.5% 的次数。合格基因票可替换热度第 1 名；基因票可触发仓位 ×1.15。

阈值 · 近涨停：r_d ≥ 9.5%

信号日收盘价（close）

close

Top5 表与 K 线高亮用的信号日收盘价；尾盘腿通常以接近该价格成交（如 14:45 近收）。

选股门槛

Score 分差（margin）

margin

热度第 1 名与第 2 名的 Score 相对差，衡量「第一名是否足够领先」。margin 过小说明 Top2 逼近， conviction 不足，非高潮日可直接空仓。

阈值 · 典型硬门：margin < 3% → 空仓

最小分差门槛（min_margin）

gates.min_margin

JSON gates.min_margin 给出的当日最小 margin 要求；低于该值且非特殊 walk 规则时执行 conviction_skip，记录为 empty。

高潮日（climax）

gates.climax_*

当日涨幅与量比同时过热时视为高潮。高潮日通常仓位 ×0.5，或跳过该候选；也可触发 climax_day_skip 直接空仓。

阈值 · 默认：θ_r = 4%，θ_b = 2

人气增量（attn_rise）

attn_rise

热榜注意力相对前一日的变化。walk 规则中 Δattn < 0 的候选会被跳过；是 ths_v15 中权重 0.18 的核心因子。

阈值 · 硬门：Δattn < 0 → 跳过

分腿执行

分腿权重（w_close / w_open）

w_close, w_open

总仓位拆成尾盘腿与次日开盘腿。实盘定稿常用 25% / 75%（或研究对照 15% / 85%），在 T 日 14:45 与 T+1 09:30 分两笔成交。

阈值 · 默认：25% 尾盘 + 75% 次开

隔夜 gap 带

gap_band

次日开盘价相对信号日收盘的跳空幅度。仅当 g 落在 gap 带内（默认 [−2.2%, +2%]）才执行开盘腿；否则 outside_gap 仅保留尾盘 stub。

阈值 · 默认：g ∈ [−2.2%, +2%]

综合买入价（buy_px）

buy_px

分腿成交后的加权平均成本；若开盘腿未成交则退化为尾盘价 C_T。

尾盘腿（leg_close）

leg_close

T 日 14:45 买入的份额；T+1 收盘卖出（除非 lock 触发持有隔夜腿）。

开盘腿（leg_open）

leg_open

T+1 09:30 在 gap 带内加仓的份额；卖点由 lock / regime / fuse 状态机在 T+1 收或 T+2 开/收决定。

Lock 卖点

exit_rules.lock_t1_ret

T+1 收盘涨幅达到 lock 阈值（纸面 3%–4%）时，隔夜腿不于 T+1 收盘卖出，改持至 T+2 由 regime 决定 t2o / t2c。

阈值 · 常见：θ_lock = 3% 或 4%

Regime 统计（T+2 卖点）

exit_rules.regime_*

T+2 开盘→收盘收益的 18 日滚动均值。均值为负时倾向 t2o（T+2 开盘卖）；T+1 下影 > 2% 时可 lw_hold 改持到 T+2 收盘。

K 线与价格

K 线（OHLC）

每根蜡烛表示一个交易日的开高低收。收盘 ≥ 开盘为阳线（涨，红色 #e11d48）；反之为阴线（跌，绿色 #059669）。信号日可在图上高亮。

模型收益

月收益率

retPct

模型页逐月收益；由回测账本按自然月聚合，含 T+1 可卖、成本与硬顶约束。

复合年化区间收益

y2025, y2026, from2025

对所选月份序列连乘月收益得到区间总收益；模型页 y2025 / y2026 / from2025 均用此复合公式。

累计净值

nav

月表逐月连乘的净值曲线；累计列显示 (NAV - 1) × 100%。

账户与仓位

可用现金（cash_before）

cash_before

买入前账户现金；A 股按 100 股一手取整得 shares / lots。

仓位系数

size_scale

在基础分腿权重上叠乘：高潮 ×0.5、连跌 3 日 ×0.5、基因票 ×1.15、近 5 日大赢 ×1.10 等；亏后空 1 日、同代码冷却 10 日。

热度打分 Score^hot

同花顺/东财热榜思路的可执行近似。每日在可交易池内做截面标准化，再加权求和得到 Top-N 候选。

  • 截面 z-score 只在当日 universe 内计算，避免前视。
  • amt_burst < 1.2 的票直接不进候选池。
  • ext_burst / weak_close 等硬门可踢掉高潮追高腿。

选股：v30 → v33 机制核

在 Top5 热度里按规则 walk，最终每天最多持 1 只。v35-light / v36 只改执行与杠杆，不改选股核。

顺序条件动作
硬门第1、第2名分差 < 3%（非高潮）空仓
硬门人气增量 < 0跳过该腿
1人气全空，且沪深300近5日 ≤ 0热度第2名
2人气全空，指数近5日 > 0热度第1名
3第2名为合格基因票100% 改选第2名
4第1名高潮 / 连跌3日 / 下影>3%前5里下一只合格基因票
5其余热度第1名
  • 合格基因票：近20日（不含当日）近涨停 ≥ 1 次，且非连跌3日、非高潮。
  • 高潮 = 当日涨 > 4% 且量比 > 2；近涨停 = 单日 ≥ 9.5%。

执行：分腿买卖与卖点状态机

实盘 harden+v2.2 与纸面 v33 共用选股，差异在 lock 阈值、弱开加重与 roll_lock。默认 15/85 或 25/75 尾盘+次开。

时刻规则
T 14:45买尾盘腿（25% 或 15%）；弱开带内可加重 overnight 腿
T+1 09:30在 gap ∈ [−2.2%, +2%] 内买开盘腿（75% 或 85%）
T+1 收盘卖掉尾盘腿；T+1 收 ≥ lock 阈值则隔夜腿不卖
T+2 09:30lock / fuse / regime<0 → t2o；否则 t2c 拿到 T+2 收盘
T+1 下影 > 2%取消 regime 的 t2o，改持到 T+2 收盘（lw_hold）
  • regime 统计：T+2 开盘→收盘的 18 日滚动均值，< 0 则 t2o。
  • fuse：基因仓 T+1 开收 ≤ 0 时强制 t2o，防隔夜跳空。
  • v35-light 补丁：弱开 5/95、fuse0、lock 日再加仓 15%。
