实验背景

Runge 现象

1901年，数学家 Carl Runge 发现了一个令人困惑的现象：对于函数f(x)=11+25x2f(x)=\frac{1}{1+25x^2}f(x)=1+25x21​ 在区间x∈[−1,1]x\in[-1,1]x∈[−1,1] 上，如果选择n+1n+1n+1 个 等间距 的节点对区间进行均匀剖分，并构造其 Lagrange 插值多项式Pn(x)P_n(x)Pn​(x)。随着插值多项式阶次nnn 的递增，插值误差En(x)=∣f(x)−Pn(x)∣E_n(x) = |f(x) - P_n(x)|En​(x)=∣f(x)−Pn​(x)∣ 的行为表现出明显的两极分化：误差在区间中心x≈0x \approx 0x≈0 附近 递减 ，然而，误差在区间边缘x≈±1x \approx \pm 1x≈±1 附近却 递增，Pn(x)P_n(x)Pn​(x) 在端点附近出现剧烈的振荡。这种在高次多项式等距插值中，误差在区间边缘迅速发散的现象，被称为 Runge 现象。

Runge 现象的数学解释

我们对Runge现象给出一个通俗的解释：

Runge 现象的根本原因是我们在使用等距节点进行高次插值时，插值误差项En(x)E_n(x)En​(x) 表达式中的两个关键因子在高阶时共同发散。

设Pn(x)P_n(x)Pn​(x) 为在节点{x0,x1,…,xn}\{x_0, x_1, \dots, x_n\}{x0​,x1​,…,xn​} 上插值函数f(x)f(x)f(x) 的nnn 次多项式。若f∈Cn+1[a,b]f \in C^{n+1}[a,b]f∈Cn+1[a,b]，则对任意x∈[a,b]x \in [a,b]x∈[a,b]，存在ξ=ξ(x)∈(a,b)\xi = \xi(x) \in (a,b)ξ=ξ(x)∈(a,b) 使得

def lagrange_barycentric(x_nodes, y_nodes, x_eval):
    n = len(x_nodes)
    P = np.zeros_like(x_eval, dtype=float)
    weights = np.zeros(n)

    # 1. 计算重心权重 w_j
    for j in range(n):
        prod = 1.0
        for k in range(n):
            if k != j:
                prod *= (x_nodes[j] - x_nodes[k])
        weights[j] = 1.0 / prod if abs(prod) > 1e-20 else 0.0

    # 2. 对每个待评估点 x_eval 进行插值
    for i, x in enumerate(x_eval):
        # 处理 x 恰好是节点的情况
        if np.any(np.abs(x - x_nodes) < 1e-12):
            idx = np.argmin(np.abs(x - x_nodes))
            P[i] = y_nodes[idx]
            continue

        num = den = 0.0
        for j in range(n):
            diff = x - x_nodes[j]
            w = weights[j] / diff
            num += w * y_nodes[j]
            den += w

        # 应用重心公式 P_n(x) = num / den
        P[i] = num / den if abs(den) > 1e-20 else y_nodes[np.argmin(np.abs(x - x_nodes))]
    return P

def f_runge(x):
    return 1 / (1 + 25 * x**2)

y_true_runge = f_runge(x_plot)
degrees_all = [2, 4, 6, 8, 10, 12, 14, 16]
